# Breast Cancer Classification

**What it does:** Predicts malignant vs benign from 30 cell-image measurements. *Educational — not a medical tool.*
**Dataset:** Wisconsin Diagnostic Breast Cancer — 569 samples (built into scikit-learn).
**Verified result:** Logistic Regression **98.6%** · Random Forest **95.8%**.
**Files:** `breast_cancer_classification.ipynb` · `confusion_matrix.png`
