# Iris Flower Classification

**What it does:** Predicts an iris flower's species (setosa / versicolor / virginica) from 4 measurements.
**Dataset:** Fisher's classic Iris dataset — 150 flowers (built into scikit-learn).
**Verified result:** Logistic Regression **94.7%** · Random Forest **89.5%** (38-flower test split — small data, jumpy scores).
**Files:** `iris_classification.ipynb` · `confusion_matrix.png`
