# Wine Quality Prediction

**What it does:** Predicts whether a red wine is "good" (expert score ≥ 7) from 11 chemical measurements.
**Dataset:** UCI Wine Quality — 1,599 red wines.
**Verified result:** Random Forest **94.0%** · Logistic Regression **89.3%**. Top signals: alcohol + sulphates.
**Files:** `wine_quality_prediction.ipynb` · `confusion_matrix.png` · `feature_importance.png`
