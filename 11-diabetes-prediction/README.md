# Diabetes Prediction

Predicts whether a patient has diabetes from 8 clinical measurements, using the classic **Pima Indians Diabetes** dataset (768 patients; 34.9% positive).

## Verified result (executed notebook)
- **Random Forest: 75.5% accuracy** ✅ best
- Logistic Regression: 73.4%

## Run it
Open `diabetes_prediction.ipynb` — it downloads the dataset itself (two mirrors included) and runs end to end.

## Honest note
75% is typical for this small, old dataset — it is a teaching benchmark, not a medical tool. Screening models support clinicians; they never replace them.
